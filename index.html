⚡ Issue 1: Marker Zoom Eşiği (Threshold) %10 Puan

Çok sayıda işaretçinin haritada üst üste binip okunabilirliği bozmasını önlemek için ZOOM_THRESHOLD = 15 eşik değeri belirlenmiştir. Uzak bakışta sadece ana bölüm binası görünürken, yakınlaşıldığında (Zoom ≥ 15) alt araştırma laboratuvarları ve GNSS istasyonları otomatik olarak eklenir.

if (map.getZoom() >= 15) { map.addLayer(subMarkers); } else { map.removeLayer(subMarkers); }
🌍 Issue 2: Dünyanın Tekrarlanması (Earth Repeating) %10 Puan

Harita uzaklaştırıldığında dünyanın doğu-batı ekseninde sonsuz yatay kopyalar oluşturması, noWrap: true karo ayarı ve sınır kısıtlaması (maxBounds & maxBoundsViscosity: 1.0) ile tamamen engellenmiştir. Harita tek bir gerçek dünya sınırı içinde sabit kalır.

L.tileLayer(url, { noWrap: true, bounds: [[-85, -180], [85, 180]] }); map.setMaxBounds([[-85, -180], [85, 180]]);
